# Portfolio — Muhammad Doni Saputra

Portofolio statis menggunakan HTML, CSS, JavaScript, Bootstrap, Font Awesome, dan Devicon.

## Struktur folder
```text
portfolio-doni-fixed/
├── index.html
├── style.css
├── script.js
└── assets/
    └── img/
        ├── foto-doni.jpg
        └── certificates/
            ├── java-fundamentals.jpg
            ├── plsql-database.jpg
            ├── ccnav7.jpg
            ├── toefl-brighten.jpg
            └── business-analysis.jpg
```

## Cara menjalankan
1. Ekstrak ZIP.
2. Buka folder di Visual Studio Code.
3. Masukkan foto profil sebagai `assets/img/foto-doni.jpg`.
4. Masukkan gambar sertifikat asli ke `assets/img/certificates/` dengan nama file yang sesuai.
5. Perbarui tautan LinkedIn, GitHub, dan tautan proyek di `index.html`.
6. Buka `index.html` atau jalankan dengan ekstensi Live Server.

## Catatan
- Bagian Home, About, Skills, Tools, Projects, Certifications, Contact, dan Footer tersedia.
- Kartu Skills dan Tools memiliki efek hover.
- Klik kartu sertifikat untuk memperbesar gambar. Tutup dengan tombol ×, klik area gelap, atau tekan Esc.
- Sertifikat yang belum memiliki gambar akan menampilkan pesan dalam popup.
- Pastikan informasi profil, IPK, tanggal, tautan, dan gambar sertifikat telah diverifikasi sebelum dipublikasikan.
- Situs menggunakan CDN untuk Bootstrap, Font Awesome, Devicon, dan Google Fonts, sehingga koneksi internet diperlukan untuk memuat aset tersebut.
